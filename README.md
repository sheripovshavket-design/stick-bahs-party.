# Stick Bash Party

Оригинальная браузерная мини-игра в духе локальных party games. Это не копия оригинальных ресурсов Stickman Party.

## Запуск на телефоне
1. Создай репозиторий на GitHub, например `stick-bash-party`.
2. Загрузи `index.html` и `README.md` в репозиторий.
3. Открой **Settings → Pages**.
4. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем Save.
5. Открой адрес GitHub Pages, который появится в настройках.

## Управление
- Игрок 1: WASD
- Игрок 2: стрелки
- Игрок 3: IJKL
- Игрок 4: TFGH
- На телефоне: выбери игрока в кнопках под полем и пользуйся стрелками.
